# Elevation Tokens

Elevation tokens are used to give elements the appearance of being raised off the page. Use them with the `box-shadow` property. These are especially useful for menus, popovers, and dialogs.

### Elevation

| Token | Preview |
|-------|---------|
| `--terra-shadow-x-small` | `0 1px 2px hsl(240 3.8% 46.1% / 6%)` | <div class="elevation-demo" style="box-shadow: 0 1px 2px hsl(240 3.8% 46.1% / 6%);"></div> |
| `--terra-shadow-small` | `0 1px 2px hsl(240 3.8% 46.1% / 12%)` | <div class="elevation-demo" style="box-shadow: 0 1px 2px hsl(240 3.8% 46.1% / 12%);"></div> |
| `--terra-shadow-medium` | `0 2px 4px hsl(240 3.8% 46.1% / 12%)` | <div class="elevation-demo" style="box-shadow: 0 2px 4px hsl(240 3.8% 46.1% / 12%);"></div> |
| `--terra-shadow-large` | `0 2px 8px hsl(240 3.8% 46.1% / 12%)` | <div class="elevation-demo" style="box-shadow: 0 2px 8px hsl(240 3.8% 46.1% / 12%);"></div> |
| `--terra-shadow-x-large` | `0 4px 16px hsl(240 3.8% 46.1% / 12%)` | <div class="elevation-demo" style="box-shadow: 0 4px 16px hsl(240 3.8% 46.1% / 12%);"></div> |
