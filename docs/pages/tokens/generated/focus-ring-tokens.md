# Focus Ring Tokens

Focus Ring Tokens are used to define the highlighted ring that surrounds interactive elements that have control focus. Focus ring tokens control the appearance of focus rings. Note that form inputs use [--terra-border-interactive-focus-ring](/tokens/generated/foundation-tokens/#border-colors-for-neutral-interactive-surfaces) tokens instead.

### Style And Layout

| Token | Value |
|-------|-------|
| `--terra-focus-ring-style` | `solid` |
| `--terra-focus-ring-width` | `3px` |
| `--terra-focus-ring` | `var(--terra-focus-ring-style) var(--terra-focus-ring-width) var(--terra-focus-ring-color)` |
| `--terra-focus-ring-offset` | `1px` |
