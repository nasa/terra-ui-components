# Transition Tokens

Transition tokens are used to create consistent transition durations for animations and interactions. They use milliseconds (ms) as the unit of time.

### Transition

| Token | Value | Preview |
|-------|-------|---------|
| `--terra-transition-x-slow` | `1000ms` | <div class="transition-demo" style="transition-duration: 1000ms;"></div> |
| `--terra-transition-slow` | `500ms` | <div class="transition-demo" style="transition-duration: 500ms;"></div> |
| `--terra-transition-medium` | `250ms` | <div class="transition-demo" style="transition-duration: 250ms;"></div> |
| `--terra-transition-fast` | `150ms` | <div class="transition-demo" style="transition-duration: 150ms;"></div> |
| `--terra-transition-x-fast` | `50ms` | <div class="transition-demo" style="transition-duration: 50ms;"></div> |
